AI Tuber Widget Embed Examples

🎤 Important: Microphone & Audio Permissions

For voice features to work in iframes, you must include these permissions:

  • allow="microphone; autoplay; speaker-selection"
  • allowfullscreen (for full audio context access)

Note: The user must click/interact with the iframe for AudioContext to start (browser security requirement).

Basic Widget

Simple embedding with default settings and microphone permissions: 

<iframe 
    src="http://localhost:3000/widget?theme=light&width=800px&height=600px"
    width="800" 
    height="600"
    frameborder="0"
    allow="microphone; autoplay; speaker-selection"
    allowfullscreen>
</iframe>

    id="ai-widget"
    src="http://localhost:3000/widget?postMessages=true&allowFullscreen=true"
    width="800" 
    height="600"
    frameborder="0"
    allow="microphone; autoplay; speaker-selection"
    allowfullscreen>
</iframe>

<script>
// Send message to widget
function sendMessage() {
    const iframe = document.getElementById('ai-widget');
    iframe.contentWindow.postMessage({
        type: 'SEND_MESSAGE',
        message: 'Hello from parent!'
    }, '*');
}

// Listen for messages from widget
window.addEventListener('message', function(event) {
    if (event.data.type === 'WIDGET_READY') {
        console.log('Widget is ready!');
    }
    if (event.data.type === 'CHAT_UPDATE') {
        console.log('Chat updated:', event.data.chatLog);
    }
    if (event.data.type === 'TOGGLE_FULLSCREEN') {

Configuration Options

Available URL parameters for customization:

Parameter Type Default Description
width string 800px Widget width
height string 600px Widget height
theme string light Theme: light, dark, minimal
showBackground boolean true Show background image
showCharacter boolean true Show 3D character
showChatLog boolean true Show chat history
characterName string CHARACTER Character display name
characterModel string default Path to VRM or Live2D model
systemPrompt string default AI personality prompt
postMessages boolean false Enable parent communication
showProfileOverlay boolean false NEW: Show profile overlay button to view user preferences learned by MamaSan

PostMessage Events

Events sent from widget to parent (when postMessages=true):

Event Type Description Payload
WIDGET_READY Widget has loaded and is ready for interaction None
CHAT_UPDATE Chat log has been updated with new messages { chatLog: Message[] }
WIDGET_CHAT_PROCESSING Widget is processing a chat message None
WIDGET_CHAT_DONE Widget finished processing chat message { message: string }
CHAT_ACTION_CARDS_UPDATE NEW: MamaSan sends host recommendation cards with images {
  actionCards: Array<{
    id: string,
    title: string,
    description: string,
    data: { image: string, tags: string[] }
  }>
}
MAMASAN_SEARCH_READY NEW: MamaSan personality analysis completed, search query ready {
  searchQuery: string,
  answers: string[],
  userPreferences: {...}
}
WIDGET_ERROR Error occurred in widget { reason: string, error?: string }

MAMASAN_SEARCH_READY Event Details

This event is triggered when the user completes the MamaSan personality analysis flow. The payload contains: 

{
  type: 'MAMASAN_SEARCH_READY',
  payload: {
    searchQuery: "What kind of mood are you in today? I'm in a happy mood | Do you have a preferred type? Yes, a girl who likes playing video games | What kind of conversation do you enjoy? mainly talking about video games or anime | Do you enjoy any particular service? (e.g., karaoke, games, deep talk, etc.)? hello | Would you like to relax, or are you in the mood for something lively? relax",
    answers: [
      "I'm in a happy mood",
      "Yes, a girl who likes playing video games", 
      "mainly talking about video games or anime",
      "hello",
      "relax"
    ],
    userPreferences: {
      rawAnswers: [...],
      searchTerms: "...",
      completedAt: "2023-12-07T10:30:00.000Z",
      step: "mamasan_recommend"
    }
  }
}

Commands sent from parent to widget:

Command Type Description Payload
SEND_MESSAGE Send a message to the widget { message: string }
CLEAR_CHAT Clear the chat history None
WIDGET_CONFIG Update widget configuration { config: {...} }
